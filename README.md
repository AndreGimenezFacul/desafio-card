# Card de prévia de estatísticas

## Sobre o projeto

Este projeto é o desafio de card de prévia de estatísticas da disciplina de Design e Desenvolvimento Frontend. A proposta era montar uma página parecida com o exemplo passado pelo professor, usando HTML e CSS.

## A página

O card mostra um texto sobre análise de dados, três estatísticas e uma imagem de pessoas trabalhando em um escritório. O fundo é escuro, com alguns detalhes em roxo, incluindo o efeito aplicado sobre a foto. As fontes usadas são Inter e Lexend Deca, carregadas pelo Google Fonts.

## O layout

No computador, o texto e as estatísticas ficam ao lado da imagem. No celular, a imagem fica em cima e o conteúdo aparece abaixo, com as estatísticas uma embaixo da outra. O CSS usa Grid, Flexbox e media queries para organizar esses elementos e ajustar o tamanho das fontes e os espaçamentos. A página é apenas visual, sem botões ou JavaScript.

## Como abrir

Para abrir, basta baixar o repositório, extrair os arquivos e abrir o index.html no navegador. O style.css e a pasta images precisam ficar junto do HTML. Não precisa instalar nada. É necessário ter conexão com a internet para carregar as fontes do Google Fonts; sem ela, o navegador usa uma fonte padrão.
